# 11. 将来拡張（優先度低）

本仕様の範囲外とし、将来のバージョンで検討する機能。

| 機能                      | 説明                                                                                                                                                            |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DMN形式エクスポート       | Decision Model and Notation（OMG標準XML）としてエクスポート。他ツールとの連携に使用                                                                             |
| コード出力                | テーブルをJavaScript / Python / SQL CASE WHEN式としてエクスポート                                                                                               |
| バッチ結果のCSVエクスポート | バッチ評価で得た結果一覧をCSVとして保存する機能                                                          |
| 画面内テストケース編集    | CSVファイルを使わず、評価パネル内でテストケースをExcelライクなグリッドで直接追加・編集する機能                                                                  |
| CSV / Excelインポート     | 既存のExcelで書かれたルール表を取り込む                                                                                                                         |
| Undo / Redo               | `Ctrl+Z` / `Ctrl+Y` による編集履歴の巻き戻し（エントリーテーブル変更など破壊的操作に特に重要）                                                                  |
| 数値範囲の網羅性チェック  | ドメイン定義（min〜max）を前提とした数値フィールドのカバレッジ確認                                                                                              |
| 到達不能行の完全検出      | `between`・`in`・比較演算子を含む複雑な条件間の包含判定（[spec_quality_checks.md §6.3](spec_quality_checks.md) の近似を超えた実装）                                  |
| URLシェア                 | ロジック状態をBase64エンコードしてURLに埋め込み、リンク1本で共有（注: ロジックが大きい場合はURL長制限に達するため、将来的にはバックエンドサーバーが必要になる） |
| 印刷対応 / PNG出力        | テーブルをドキュメントとして共有・提出                                                                                                                          |
| 複数ロジックの管理        | 同一セッションで複数のロジックを切り替え・一覧表示する機能                                                                                                      |
