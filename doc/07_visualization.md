# 7. 可視化

## 7.1 テーブル内フローチャート（ミクロ可視化）

1つのテーブルを対象として、条件分岐の構造をフローチャートとして生成・表示する。

### 表示位置

各テーブルエディタのヘッダーに「テーブル / フローチャート」のタブスイッチャーを配置する。フローチャートタブを選択すると同一ペイン内でフローチャート表示に切り替わる（別画面遷移ではない）。

### 描画ルール

- 条件列の共通プレフィックスはノードを合流させる（例: 行1と行2が同じ第1条件を持つ場合は分岐を共有）
- 終端結論ノードは緑系の枠で表示し、出力列の値をノード内に表示する
- 継続参照ノードは「→ テーブル名」として表示する
- 更新はテーブル編集と連動してリアルタイムで行う

### カバレッジギャップの可視化（ファントムノード）

§6.8 のカバレッジ計算で**未定義パターン**が見つかった場合、フローチャート上にそのギャップに対応する**ファントムノード**を描画する。

- ファントムノードはグレーアウトされた点線枠で表示し、ラベルとして「未対応 / No rule」を付ける
- ノードのツールチップで「このブランチには対応する行がありません」と表示する
- カバレッジギャップが1件以上存在する場合、テーブルビュー側にも黄色のバナー警告とフローチャートへのジャンプリンクを表示する（フローチャートタブのバッジにもギャップ件数を表示）

ファントムノードはユーザーに「フローチャートとしては枝が伸びているのに対応する行がない」状態を視覚的に伝えることで、抜け漏れの発見を支援する。

### ナビゲーション

- フローチャートのノードをクリックすると、テーブルビューへ自動的に切り替わり、対応する行がハイライト表示される（双方向ナビゲーション）
- 継続参照ノードをクリックした場合の挙動は将来対応（現バージョンでは強調表示のみ）

### エクスポート対応

SVG / PNG ダウンロードは将来対応とする。

## 7.2 テーブル間DAGグラフ（マクロ可視化）

ロジック全体のテーブル依存関係を有向グラフとして表示する。

- 表示位置: 左ペインの「テーブル関係図」アコーディオンセクション
- ノード: 各テーブル（テーブル名を表示）
- 有向辺: 継続参照（`continue`）の関係
- エントリーテーブルは「▶ 入口」マーカーで視覚的に区別する
- ノードをクリックすると、そのテーブルのエディタが右ペインに表示される

このグラフは**ロジック全体の地図**として、左ペインのアコーディオンを開いている間は常時参照できる。
